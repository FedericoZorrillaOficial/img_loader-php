  # img_loader-php
  
  Mini proyecto para subir imágenes con **PHP, HTML, CSS y JavaScript**.
  
  Permite seleccionar una imagen, mostrar una vista previa en el navegador y enviarla al servidor para guardarla en una carpeta local.
  
  
  ## Tecnologías
  
  - HTML5
  - CSS3
  - JavaScript
  - PHP
  
  
  ## Funcionalidades
  
  - Input de imagen personalizado.
  - Vista previa antes de subir.
  - Envío con `multipart/form data`.
  - Recepción del archivo con `$_FILES`.
  - Guardado con `move_uploaded_file()`.
  
  
  ## Estructura
  
  ```txt
  img_loader-php/
  ├── index.html
  ├── css/
  │   └── style.css
  ├── js/
  │   └── control.js
  ├── php/
  │   └── loader.php
  └── imagenes/
  ```
  
  
  ## Nota técnica
  
  El proyecto puede usar time() para generar nombres únicos al subir imágenes.
  En la demo está desactivado para evitar llenar el hosting con archivos innecesarios.
  
  
  
  ## Objetivo
  
  Practicar el flujo completo de carga de imágenes desde el frontend hasta el backend, útil para formularios, perfiles, catálogos y paneles administrativos.
